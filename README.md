# Recibo de sueldo de encargados de consorcio

Aplicación web (React + Vite + TypeScript) para armar la liquidación y un recibo imprimible de haberes del encargado de un consorcio en Argentina: datos del consorcio y del empleado, período, haberes y descuentos, total líquido.

## Uso local

```bash
npm install
npm run dev
```

Generá PDF desde el navegador con **Imprimir / PDF** (impresión a archivo).

## Build

```bash
npm run build
npm run preview
```
